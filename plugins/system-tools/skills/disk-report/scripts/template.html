폴더 탐색

드라이브 맨 위부터 폴더를 열어 내려갈 수 있습니다. 100MB가 넘는 폴더만 보이고, 막대는 드라이브 사용량 전체 대비 비율입니다.

설치된 앱과 마지막 사용

"마지막 사용"은 Windows 실행 기록, Steam 플레이 기록 순으로 찾고, 둘 다 없으면 앱 폴더에서 가장 최근에 바뀐 파일 날짜로 대신합니다. 근거 열에 무엇을 썼는지 적었습니다.

앱 크기 마지막 사용 근거

앱 데이터 폴더 (AppData · ProgramData)

200MB가 넘는 앱 데이터 폴더를 설치된 앱 목록과 이름으로 맞춰 봤습니다. "연결된 앱 없음"은 지운 앱이 남긴 찌꺼기일 수 있지만, 이름이 달라서 못 맞춘 경우도 있으니 후보로만 보세요.

자주 묻는 것

최대 절전 파일 (hiberfil.sys)

최대 절전 모드는 PC를 끌 때 메모리 내용을 디스크에 통째로 저장해 두었다가, 켤 때 그대로 되살리는 기능입니다. 그 저장 공간을 Windows가 미리 잡아 두는데, 지금 입니다.

최대 절전을 안 쓰면 관리자 터미널에서 powercfg /h off로 끄고 공간을 돌려받을 수 있습니다. 대신 Windows "빠른 시작"도 같이 꺼져서 부팅이 몇 초 느려질 수 있습니다. 일반 절전(모니터만 끄고 대기)은 그대로 됩니다.

가상 메모리 파일 (pagefile.sys)

메모리가 모자랄 때 디스크를 임시 메모리로 쓰는 파일입니다. 지금 입니다. Windows가 크기를 알아서 조절하므로 그대로 두는 걸 권합니다.

Claude · Codex 데이터

Claude-Data : 지금 쓰고 있는 Claude 데스크톱 앱의 작업 폴더입니다. 세션마다 만드는 임시 작업 폴더와 앱 데이터가 들어 있습니다. 앱이 관리하므로 직접 지우지 말고, 오래된 세션을 앱에서 삭제하는 쪽이 안전합니다.

.codex : OpenAI Codex의 데이터입니다. 대화 기록(sessions) , 생성한 이미지 가 대부분입니다. 예전 대화를 다시 볼 일이 없다면 오래된 월 폴더를 지워도 됩니다.

측정 방법과 한계

모든 파일의 크기를 직접 더했습니다. 접근이 막힌 시스템 보호 영역(시스템 복원 지점, 파일 시스템 내부 기록)은 열 수 없어서 "측정 불가"로 따로 적었습니다.

Docker·WSL 가상 디스크는 파일 크기 기준이라 실제 차지하는 공간과 조금 다를 수 있습니다. 앱 "마지막 사용"은 Windows가 남긴 실행 기록이 일부 앱에만 있어서, 없는 앱은 폴더 변경일(업데이트 포함)로 대신했습니다.
